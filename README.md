# 매치? 매치! — MEGA MT 사진 매칭 게임 사이트

무료 Firebase(Spark 요금제, 카드 등록 없음)로 돌아가요. Firestore(실시간 DB) + 익명 로그인 + Hosting만 씁니다.

## 화면 3개

| 주소 | 누가 | 용도 |
|---|---|---|
| `/` | 참가자 휴대폰 | 방 코드/QR로 입장 → 팀·그룹 선택 → 사진 선택·제출 |
| `/host.html?room=코드` | 진행자 노트북 | 준비(사진·주제), 진행(주제 공개·마감·공개·타이머), 빔 화면 조작, 점수 |
| `/screen.html?room=코드` | 빔프로젝터 | 관객용 큰 화면 (조작 버튼 없음) |

진행자는 첫 화면에서 **새 게임 방 만들기**를 누르면 방이 생기고 진행자 화면으로 넘어가요.

---

## 1. Firebase 준비 (한 번만, 약 10분)

1. https://console.firebase.google.com → **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. 왼쪽 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명 → 사용 설정 → 저장**
3. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작 (규칙은 아래 배포 때 같이 올라가요)
4. 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱 → 웹(</>)** 아이콘으로 앱 등록 (Hosting 체크는 안 해도 됨)
5. 화면에 나오는 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 **`js/firebase-config.js`** 에 붙여 넣기
6. **`.firebaserc`** 의 `여기에_프로젝트ID`를 내 프로젝트 ID로 바꾸기

## 2. 배포 (PC에 Node.js 필요)

이 폴더에서 터미널을 열고:

```bash
npm install -g firebase-tools
firebase login
firebase deploy
```

끝나면 `https://프로젝트ID.web.app` 주소가 나와요. 이 주소가 사이트예요.
`firebase deploy` 한 번으로 **사이트 + Firestore 보안 규칙**이 같이 올라가요.
코드를 고친 뒤에도 같은 명령만 다시 치면 돼요.

---

## 3. 당일 진행 순서

1. 노트북 크롬에서 사이트 → **새 게임 방 만들기** (시크릿 창 X — 방을 만든 브라우저가 진행자로 기억돼요)
2. **준비** 탭: 라운드 수, 팀 이름, 사진 30장(여러 장 한 번에 선택 가능, 파일 이름순 정렬), 라운드별 주제 7개
3. 우측 상단 **빔 화면 열기** → 새 창을 빔 쪽 모니터로 옮기고 오른쪽 아래 **전체화면**
   (노트북 디스플레이 설정은 “화면 확장” 모드)
4. **진행** 탭의 QR/링크로 8그룹 입장 → 입장 현황에서 8/8 확인
5. **1라운드 시작 · 주제 공개** → 선택 → **제출 마감** → **답 공개** → 빔 화면 버튼으로 팀별 비교·주제 확대·전체 팀 표 전환
6. 마지막 라운드 공개 후 **최종 결과 발표**

### 운영 팁
- **마감 취소**: 공개 전까지는 “마감 취소 · 제출 다시 열기”로 되돌릴 수 있어요.
- **휴대폰 교체/그룹 잘못 선택**: 진행 탭 그룹 칸의 **기기 변경 허용** → 새 휴대폰에서 그 그룹을 누르면 이어받아요. 저장된 선택·제출 기록은 유지돼요.
- 게임 시작 전이면 참가자가 스스로 “그룹을 잘못 골랐어요”로 다시 고를 수 있어요.
- 타이머는 표시용이에요. 0초가 돼도 자동으로 마감·제출·공개되지 않아요.
- 동점은 공동 순위로 표시돼요.
- 진행자 화면(“점수·답안” 탭 포함)에서는 **답 공개 전에는 답안이 보이지 않아요.** 보안 규칙상 공개 전 답안은 진행자 기기로도 전송되지 않아요.

## 4. Firebase 없이 미리 해보기 (리허설용 가짜 서버)

주소 끝에 `?mock=1`을 붙이면 Firebase 없이 **같은 브라우저 안에서만** 동작하는 가짜 서버로 돌아가요.
빔 화면 배치·버튼 흐름을 미리 확인할 때 쓰세요. (다른 기기와는 연결되지 않음)

```bash
npx serve .          # 또는 python -m http.server 8000
```
→ `http://localhost:3000/?mock=1` 에서 방 만들기.
같은 브라우저에서 휴대폰 역할 창을 여러 개 띄우려면 주소에 `&mockuid=p1`, `&mockuid=p2` …를 각각 붙이세요.

## 무료 한도 (Spark 요금제)

Firestore 하루 읽기 5만·쓰기 2만, 저장 1GB, Hosting 저장 10GB·전송 월 10GB.
24명·8대 기준 한 게임은 한도의 몇 % 수준이라 여유 있어요. 사진은 자동으로 장당 600KB 이하로 줄여서 저장해요.
